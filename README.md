# Sistema de Gestão - Clínica Pediátrica Pequenos Passos

## Como executar localmente
1. Crie o banco `clinica_pediatrica` no PostgreSQL e execute o arquivo `../clinica_pediatrica.sql`.
2. Copie o arquivo `.env.example` para `.env` e preencha os dados de acesso ao PostgreSQL (porta `7777` ou `5432`).
3. Abra o terminal na pasta `sistema/` e instale as dependências:
